## `tools.js`

Application-level utilities and UI actions. These functions are globals once `js/tools.js` is loaded.

### Text and input helpers

- `alertt(str: string): null` — Wrapper around `alert` when `testMode` is true.
- `replaceAll(str: string, searchStr: string, replaceStr: string): string`
- `inputOnKeyDown(id: string, data: { type?: string, keyword?: string }): null` — Enter key dispatcher for various inputs; calls corresponding actions like `searchOrderDetail`, `gDriveSearch`, `tracking`.
- `deleteSpecificTxt(num: string): null` — Keep only digits from input, copy to clipboard, and update `#outputText`.
- `deleteSpecificTxtAuto(e): null` — Attempts to paste automatically (legacy, not recommended).

Example:

```html
<input id="originTxt" onkeydown="inputOnKeyDown(this.id,{ type:'INVOICE_NO', keyword: this.value })" />
<button onclick="deleteSpecificTxt(originTxt.value)">변경</button>
```

### Order form helpers

- `addOrderList(): null` — Append a set of order input fields to `#orderListCon`.
- `resultorderCalc(): null` — Calculate order total from dynamic inputs, include delivery fee, update `#templeteTxt` and copy composed text to clipboard.
- `orderTxt2CopyToClipboard(): null` — Copy the composed share text for orders.
- Placeholders: `addOrderItem(option, price, ea)`, `deleteOrderItem(id)`.

Minimal usage flow:

```html
<div id="orderListCon"></div>
<pre id="templeteTxt"></pre>
<script>
  addOrderList();   // initialize one row
  // ...user fills inputs generated by addOrderList
  resultorderCalc();
<\/script>
```

### Shipping and tracking

- `orderSendInfoTemplate(num: string, cop: "0"|"1", detail: string): null` — Build a shipping notice based on carrier and selected radio group `orderSendType`. Updates output and copies to clipboard.
- `tracking(num: string): null` — Track a delivery number via CJ Logistics.
- `callHelpCenter(num: string): null` — Prompt to call carrier help center.

Carrier link helpers (constructor-style objects):

- `sweettracker()` — Methods: `getURL()`, `call()`
- `doortodoor()` — Methods: `deleveryNo(no)`, `getURL()`, `call()`
- `ds3211()` — Methods: `deleveryNo(no)`, `getURL()`, `call()`

Example:

```html
<input id="invoice" placeholder="송장번호" />
<button onclick="tracking(invoice.value)">조회</button>
```

### Returns (missing items) helpers

- `clickmissingReturnListBtn(add: 1|0): null` — Add an item row to `#missingReturnListCon` if truthy.
- `resultmissingReturnCalc(): null` — Calculate total with optional return delivery type in `#returnDeleveryType`, update text output and clipboard.

### Store/admin navigation

- `orderSearchNaver(type: string, keyword: string): void` — Navigate to Naver order management with query params.
- `goDirectAsKey(key: 'store'|'dashboard'|'order'|'return'|'exchange'|'chatbot'|'comment'|'qnas'): null` — Navigate to pre-defined admin URLs.
- `searchOrderDetail(type: string, keyword: string): null` — Navigate to order management with detail search.
- `viewOrderDetailViewPopup(productOrderNo: string): null` — Open product order detail popup by number.

Example (admin shortcuts):

```html
<button onclick="goDirectAsKey('order')">주문조회</button>
<button onclick="goDirectAsKey('return')">반품관리</button>
```

### HTML loading

- `loadHTML(elementId: string, url: string): void` — Fetch HTML and inject into `elementId`, then highlight current page link in `.codrops-demos a`.

```js
loadHTML('navigationContainer', 'navigation.html');
```

### Caveats

- Some functions rely on specific element IDs existing in the page: `#orderListCon`, `#templeteTxt`, `#missingReturnListCon`, `#returnDeleveryType`, etc.
- `setTemplateCSV` is present but not implemented.
